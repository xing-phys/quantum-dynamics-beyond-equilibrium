# Original figure provenance

All ten SVG figures are original, generated by scripts/generate_figures.jl
with Julia 1.10 standard libraries and fixed seed 20261020. No publication
figures are reproduced. Original figures are CC BY 4.0.

| Figure | Meaning and limits |
|---|---|
| concept-map | Conceptual information/sampling map; arrows are protocols |
| ensemble-geometry | Exact ensembles illustrated with finite plotted directions |
| projected-convergence | Global complex-Haar state, dA=2, dB=2…1024, 48 independent draws per size, mean trace distances k=1,2,3 with standard error; not a time evolution |
| scrooge-qubit | Adjusted Haar rejection sampling, mean eigenvalue0.8,40000 accepted draws; exact analytic density overlaid |
| swap-memory | Exact two-SWAP thought experiment with same bath |
| fragmentation-graph | All bitstrings L8,Q4,P18; exact local pair-hop graph |
| pxp-revivals | Exact open PXP L10 diagonalization, flip amplitude1, alternating and random constrained-space initial states; finite-size illustration |
| gaussian-ensemble | nbar2 Gaussian displacement samples with coherent-state quadrature width; a schematic ensemble, no inference about convergence rates |
| temporal-cut | Definition of one cut in folded influence-vector history space |
| aperiodic-words | Exact first substitution words, with physical clock caution |

Three CSV files retain data for projected convergence, the fragmentation
graph, and PXP return probabilities. Rerunning the script reproduces all
figures in the same Julia version. Individual RNG sequences may differ
between Julia releases; physical targets and seeded algorithm are explicit.
